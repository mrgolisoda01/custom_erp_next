# Requirement inbox

Put the source material for a new requirement here, then run `/intake <file>` in Claude Code.

How to bring a Claude artifact in:
- Open the artifact on claude.ai → use its download / copy option → save it here (e.g. `2026-11-04-outlet-report.html` or `.md`).
- Or copy the text and paste it straight into `/intake` — it will be saved here for you.

Also fine: PDFs, Word exports, screenshots (PNG/JPG), mail text, Excel exported to CSV.
One requirement per file (or per folder) keeps the REQ numbering clean.
